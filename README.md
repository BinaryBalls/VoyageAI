# 🌍 VoyageAI — Personalized AI Travel Itinerary Planner ✈️

VoyageAI is a full-stack, AI-powered travel planning application designed to make organizing trips easier. It helps users create personalized day-by-day travel itineraries based on their preferences, discover destinations, plan routes, and manage travel budgets.

## ✨ Features

- 🗺️ **Personalized Itineraries** — Generate travel plans tailored to individual preferences.
- 📅 **Day-by-Day Planning** — Organize activities into a structured travel schedule.
- 💰 **Budget Tracking** — Plan trips with budget awareness.
- 📍 **Destination Intelligence** — Support smarter travel decisions and destination discovery.
- 🖥️ **Full-Stack Architecture** — Separate frontend and backend components.
- 🚀 **Deployment Ready** — Includes Docker configuration and deployment setup.

## 🛠️ Tech Stack

## 🚀 Getting Started

### Prerequisites

Install the tools required by the project's actual implementation:

- Git
- Docker and Docker Compose, if using the containerized setup
- The runtime and package manager specified in the frontend and backend configuration files

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd VoyageAI
```

Replace `YOUR_REPOSITORY_URL` with the HTTPS URL of your GitHub repository.

### 2. Configure environment variables

Check the backend and frontend documentation and environment-variable examples. Create the required local environment files and provide your own API keys and configuration values.

**Never commit API keys, passwords, tokens, or production secrets.**

### 3. Run the application

If the included Docker Compose configuration supports local development, run:

```bash
docker compose up --build
```

Follow the application's configuration and terminal output for the frontend and backend URLs.

For manual setup, follow the package installation and startup commands documented in the respective `frontend/` and `backend/` directories.
